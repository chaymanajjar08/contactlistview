# ContactsListView

Projet Android Kotlin/XML conforme au TP « ListView de contacts modifiable ».

Ouvrez le dossier racine `ContactsListView` dans Android Studio et laissez Gradle synchroniser le projet. Le projet utilise Gradle Kotlin DSL, compileSdk/targetSdk 35 et minSdk 24.

## TP et exercices supplémentaires

- Sélectionner et modifier un contact.
- Ajouter un contact et supprimer par appui long avec confirmation.
- Refuser les noms vides et les doublons, sans tenir compte des majuscules.
- Trier les contacts par ordre alphabétique après les changements.
- Conserver la liste, la sélection et le texte saisi pendant une rotation.

Les données sont réinitialisées après une fermeture complète de l’application.
